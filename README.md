# KeyBridge V2 Server

The KeyBridge V2 Server for macOS and Windows, which lets SKAARHOJ controllers send keyboard and mouse input to a computer.

**[Download the latest release](https://github.com/SKAARHOJ/KeyBridge-Server/releases/latest)**

All versions are listed on the [releases page](https://github.com/SKAARHOJ/KeyBridge-Server/releases).
